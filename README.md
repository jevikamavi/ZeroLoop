# ZeroLoop

ZeroLoop is a sustainable waste management and green-services web application designed to help users manage waste responsibly and access useful environmental services in one place.

## Features

- User authentication and account management
- Waste recycling and sorting guide
- Waste pickup scheduling
- Missed pickup reporting
- Green services
- Nearby green spaces using location
- EcoPoints and rewards
- Eco marketplace
- Recent activity dashboard
- AI-powered sustainability assistant
- Responsive web interface

## Tech Stack
React • Vite • Node.js • Express • MongoDB • Leaflet

### Frontend
- React
- Vite
- React Router
- Leaflet
- React Leaflet
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT authentication

### AI
- Hugging Face Inference API

### Deployment
- Vercel — frontend
- Render — backend
- MongoDB Atlas — database
